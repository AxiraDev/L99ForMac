# Changelog

## 0.10.1 — first public beta

- GPLv3 licensing with a license copy and notices included in the app.
- English, Russian, and Simplified Chinese interface with remembered language selection.
- Optional support link to the developer's Boosty page.
- Wired USB configuration, macros, lighting controls, Photo Frame/GIF uploads, real-time Mac data, and system-audio visualization.
- Drag-to-Applications DMG for Apple Silicon.

This is a beta, with verified hardware results and remaining tests documented in [VERIFICATION.md](VERIFICATION.md). Intel, firmware updates, Bluetooth configuration, and 2.4 GHz configuration are not provided.

For earlier implementation and hardware-verification history, see [VERIFICATION.md](VERIFICATION.md).
