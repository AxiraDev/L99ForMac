# Установка с GitHub

Готовая сборка для Apple Silicon и macOS 14+ (музыкальная визуализация — 14.2+) распространяется как `L99-for-Mac-macOS-arm64.dmg`.

1. Открой DMG.
2. Перетащи **L99 for Mac** на папку **Applications («Программы»)** справа.
3. Дождись копирования и извлеки образ.
4. Запусти L99 for Mac из «Программ», подключи L99 кабелем в проводном режиме.

Rust, Python и инструменты разработчика для запуска не нужны. Приложение работает со штатными USB-интерфейсами macOS; расширение ядра не устанавливается.

## Первый запуск без подписки Apple Developer

Эта сборка имеет локальную подпись и Hardened Runtime, но не сертификат Developer ID и не нотарифицирована Apple. Образ DMG не меняет это ограничение.

Если macOS заблокировала первый запуск и ты доверяешь скачанной сборке, открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтверди открытие этого приложения. Доступность этой кнопки может зависеть от политики управляемого Mac. Отключать Gatekeeper целиком не требуется.

[Официальная инструкция Apple](https://support.apple.com/en-us/102445).

Для публикации исходников и такого DMG подписка не нужна. Для обычного запуска при стандартных настройках Gatekeeper готовую сборку следует подписать сертификатом **Developer ID Application** и нотарифицировать. Это способ распространения вне App Store; размещать приложение в Store для этого не требуется. [Developer ID](https://developer.apple.com/developer-id/).

## Данные приложения

При отдельной установке профиль хранится в собственной папке `Application Support/L99 for Mac`. Для запуска из исходного проекта используется `local-state` внутри проекта. Пользовательские профили в DMG и архив исходников не включены.

## Повторная сборка DMG

Сначала собери приложение по README. Для оформления образа нужны только при сборке:

```sh
python3 -m pip install ds-store==1.3.3 mac-alias==2.2.2
python3 scripts/package_dmg.py
```

Образ создаётся рядом с папкой проекта. Можно передать другой путь к `.dmg` первым аргументом. Оформление Finder создаётся через [ds_store](https://ds-store.readthedocs.io/en/latest/); фон рисуется собственным `scripts/DMGBackground.swift`. В готовом приложении этих Python-зависимостей нет.
