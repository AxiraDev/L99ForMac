# L99 for Mac

Русский · [English](README.md) · [简体中文](README.zh-Hans.md)

[Скачать установщик для Mac](https://github.com/AxiraDev/L99ForMac/releases/download/v0.10.1/L99-for-Mac-macOS-arm64.dmg) · [Релиз 0.10.1](https://github.com/AxiraDev/L99ForMac/releases/tag/v0.10.1) · [Сайт проекта](https://axiradev.github.io/L99ForMac/ru/)

Независимое экспериментальное приложение для настройки **AULA L99** на macOS. Ядро протокола на Rust, интерфейс SwiftUI; дополнительные среды выполнения для запуска не нужны.

Независимое приложение для настройки AULA L99 на macOS. Версия 0.10.1 распространяется под GNU GPLv3; в 0.10.0 добавлены русский, английский и упрощённый китайский интерфейс, переключение языка и окно поддержки разработчика. DMG устанавливается перетаскиванием в Applications. Профиль и настройки музыки сохраняются автоматически. Системный звук Mac управляет подсветкой клавиш и волной в плеере L99.

## Язык и поддержка

Внизу боковой панели доступны «Как в macOS», «Русский», English и 简体中文. Выбор применяется сразу и сохраняется. Названия профилей и макросов не переводятся. Системные меню и диалоги могут следовать языку macOS.

Кнопка «Поддержать» открывает окно добровольной поддержки; все функции бесплатны. Переход ведёт на [страницу автора в Boosty](https://boosty.to/axira_dev/donate) в браузере; данные карты в приложение не поступают. Ссылка задаётся в `resources/support.json`. [Подробности для сборки](LOCALIZATION.md).

## Установка

Открой `L99-for-Mac-macOS-arm64.dmg`, перетащи приложение в Applications («Программы») и извлеки образ. Сборка имеет локальную подпись; без Developer ID и нотарификации при первом запуске macOS может потребовать разрешить её в настройках. [Подробная инструкция](INSTALLATION.md).

## Запуск и загрузка картинки

Сборка предназначена для Apple Silicon и macOS 14+; музыкальная визуализация требует macOS 14.2+. Подпись локальная, без Apple Developer ID и нотарификации.

1. Подключи L99 кабелем в проводном режиме и открой приложение.
2. Открой «IPS-экран» → «Импортировать файл».
3. Выбери «Photo Frame», «Фон рабочего стола» или «GIF». Анимированный файл автоматически выбирает GIF.
4. Настрой масштаб и поворот, нажми «Загрузить на клавиатуру» и дождись проверки записи.
5. На клавиатуре выйди из соответствующего раздела и открой его заново. Для Photo Frame этот шаг проверен на настоящем устройстве.

Во время передачи оставь USB подключённым. «Остановить» отменяет оставшуюся загрузку. После остановки или обрыва подключения загрузи изображение целиком заново: продолжения с середины нет. Выбранная картинка заменяется, прошивка не обновляется. Приложение показывает успех только после проверки записанных данных контрольной суммой.

Экран — отдельное USB-устройство `EEEF:268A`, а клавиши настраиваются через HID `0C45:800A`. Загрузка изображений доступна при подключённом USB-экране, даже если интерфейса настройки клавиш сейчас нет. Обнаруженный HID-канал с output 4096 байт **не подходит для установки Photo Frame на проверенной L99**: ранняя попытка получила подтверждения, но изображение не изменилось. Рабочая реализация использует последовательный USB-порт.

Остальные изменения записываются кнопкой «Применить» в нужном разделе. По умолчанию при подключении автоматически отправляются время и показатели Mac; эти функции отключаются в Real-time Data. Перед записью конфигурация читается автоматически. Переназначения передают **весь выбранный слой**, сохраняя остальные записи по прочитанному снимку. После применения выполняется повторное чтение и сравнение отправленных настроек с полученными. Только после совпадения правки считаются применёнными; при ошибке черновик сохраняется. При ошибке первоначального чтения запись настроек недоступна.

## Назначение макроса

1. В «Макросах» создай и запиши последовательность; Esc завершает запись. Запись работает только внутри окна приложения. Установи задержки и число повторов.
2. Открой «Назначения». Выбери основной или Fn-слой и клавишу из списка, на схеме либо кнопкой «Выбрать нажатием…».
3. Для выбора нажатием оставь окно активным и нажми обычную клавишу. Esc отменяет выбор. Если клавиша уже переназначена, выбирай её в списке или на схеме: Mac получает уже изменённый код.
4. В «Действии» выбери «Макрос», его название и число повторов на этой клавише.
5. Нажми «Назначить на …». Эта кнопка сохраняет назначение в локальном профиле и отправляет макросы вместе с выбранным слоем клавиатуры.

В редакторе макросов общий счётчик меняет повторы всех назначений этого макроса. Кнопка «Применить» передаёт эти изменения вместе с телами макросов, сохраняя остальные локальные правки клавиш для отдельного применения. При разных счётчиках на клавишах чтение сохраняет каждый из них. Новые задержки ограничены 10–60000 мс; неизменённые прочитанные макросы сохраняют исходные байты.

Запись останавливается по Esc, кнопке или при потере фокуса окна. Для удерживаемых клавиш резервируется память под отпускания; при заполнении запись завершается с ними. Редактор показывает фактически занятые байты, включая индекс, служебные блоки и неподдерживаемые макросы. В пустой памяти один макрос вмещает до 325 действий; при нескольких макросах или занятых слотах доступно меньше. Для ручного редактирования есть конструктор сочетаний: выбери клавишу и Ctrl/Shift/Option/Command, нажми «Добавить сочетание». Он вставит нажатия и отпускания в правильном порядке. Недостающие отпускания после ручной правки можно добавить отдельной кнопкой.

«Сохранить назначение» только меняет локальный профиль. «Применить к клавиатуре» ниже сохраняет видимое назначение из редактора и отправляет выбранный слой. Экспорт использует ту же полную последовательность, включая зависимые макросы. Изменённый, но ещё не сохранённый редактор помечается текстом. «Сохранить профиль» сохраняет JSON-файл. При применении записывается весь выбранный слой с сохранением остальных записей из прочитанной конфигурации.

Внизу раздела «Назначения» есть поле «Проверка ввода». Для Fn-слоя в обычном режиме удерживай физическую Fn на L99 и нажми назначенную клавишу. Содержимое поля хранится только в памяти окна и очищается при уходе из раздела. Для просмотра отдельных нажатий и отпусканий нажми «Начать проверку событий»: область получает фокус и показывает последние 100 событий с временем, из них 16 последних видны в окне. Клавиши перехватываются только внутри активной области; для мыши держи курсор над ней. Esc, кнопка остановки, потеря фокуса или уход из раздела завершают проверку. Журнал в профиль и диагностику не записывается.

На реальной L99 пользователь подтвердил: физическая F12 запускает назначенный макрос с одним нажатием/отпусканием A и вводит A/Ф в поле текста. Три повтора этого макроса на F12 также проверены пользователем. На Fn+F12 проверен макрос Shift+A, отпускание Shift, пауза 500 мс и B: пользователь подтвердил две буквы и паузу. Другие модификаторы, действия мыши и остальные назначения Fn требуют отдельной проверки.

## Автосохранение и чтение L99

При подключении приложение читает подсветку, основной и Fn-слой, общие настройки, палитру и макросы. Неподдерживаемые действия отображаются как «Текущее действие» и сохраняются без изменения. Неподдерживаемые тела макросов остаются в исходном виде и не попадают в редактор. Номера слотов макросов сохраняются. До успешного чтения запись конфигурации блокируется.

Локальные изменения, ещё не отправленные кнопкой «Применить», сохраняются и переживают повторное подключение. «Загрузить с L99» заменяет их текущими настройками клавиатуры; предыдущий профиль остаётся в резервной копии. Профиль из JSON применяется поверх последнего прочитанного снимка устройства.

В исходном проекте пользовательский сеанс хранится в `local-state/session.json`, резервная копия — `local-state/session.previous.json`. При первом запуске выбери в системном окне папку этого проекта: доступ сохраняется закладкой macOS. Файлы профиля остаются в проекте; они исключены из исходного архива и Git. При отдельной установке приложения используется его собственная папка `Application Support/L99 for Mac`.

При повреждении основного файла приложение пробует последнюю корректную резервную копию. Файл сохраняется атомарно; ввод пользователя не блокируется файловыми операциями. Отдельный JSON можно экспортировать кнопкой «Сохранить профиль».

Память макросов ограничена проверенной областью 3072 байта, включая индекс 100 слотов, тела и завершающий блок. В пустой памяти один макрос вмещает до 325 действий; при нескольких макросах или наличии неподдерживаемых тел доступно меньше. Приложение проверяет фактический размер перед отправкой.

## Сон Mac и переподключение USB

При отключении USB или переходе Mac в сон старые операции отменяются. Очередь команд привязана к конкретному подключению, поэтому отложенная запись не переносится на заново подключённую клавиатуру. После подключения и пробуждения сначала читается свежая конфигурация; только затем доступны запись настроек и отправка времени/показателей. Даже при неизменном системном идентификаторе устройства после сна требуется новое чтение.

Временная ошибка чтения повторяется через 5, затем 15 и 30 секунд. Запись настроек автоматически не повторяется. Неподдерживаемый формат данных требует ручного повторного чтения или изменения поддержки протокола; бесконечного чтения такого формата нет.

Музыка останавливается при сне и отключении USB. Для продолжения нажми «Запустить»; выключение и восстановление подсветки не отправляются на новое подключение из старой музыкальной сессии. При смене аудиовыхода приложение сохраняет намерение перезапустить захват, даже если в этот момент занято чтением настроек.

Опрос присутствия USB читает только IORegistry и не создаёт HID-клиенты. Клиент HID открывается для конкретной операции. Это позволяет обнаруживать отключение во время передачи, не вмешиваясь в сам обмен.

Переходы сна, отмена передачи и запоздалые ответы проверены синтетическими тестами. Полный физический цикл сна Mac требует отдельной проверки.

## Real-time Data

1. Оставь приложение открытым и подключи L99 по USB.
2. На клавиатуре открой Home → Real-time Data.
3. В приложении одноимённый раздел показывает источник и текущие показания.

Время и дата берутся с Mac в текущем часовом поясе, с григорианским календарём. По умолчанию синхронизация выполняется при подключении и после сна Mac; при включённых показателях часы также передаются каждые 5 секунд. Для ручной отправки есть кнопка «Синхронизировать сейчас». Предпочтения сохраняются отдельно от профилей клавиш.

CPU — доля занятых процессорных тиков между измерениями; GPU — загрузка из IORegistry. Температура в поле с термометром — среднее доступных датчиков CPU, при отсутствии этих датчиков — среднее датчиков SoC. Влажность фиксирована на 0%. Интернет и погодные сервисы не используются. При недоступном датчике приложение явно показывает «Недоступно», на клавиатуру передаётся 0.

Температуры проверены на Apple M1. Чтение использует динамически загружаемые sensor API IOKit, которые могут отсутствовать или быть ограничены в других версиях macOS; в таком случае значение остаётся недоступным. Никаких привилегированных служб, изменения вентиляторов или настроек температурных датчиков нет.

Передача показателей приостанавливается во время применения настроек и загрузки изображений. Ошибки отображаются отдельно; повтор выполняется через 10 секунд, после трёх ошибок — через 30 секунд. Работа по Bluetooth/2.4 ГГц не проверена.

## Музыка

Нужна macOS 14.2 или новее и проводное USB-подключение L99.

1. Во вкладке «Музыка» нажми «Запустить». Если macOS запросит доступ, разреши запись системного аудио.
2. Включи музыку, видео или другой звук на Mac. Источник — приложения, воспроизводящие звук через текущее устройство вывода.
3. На самой клавиатуре открой плеер **Play**. Волна внизу экрана и подсветка клавиш реагируют на звук; живой спектр также виден в приложении.
4. Настрой чувствительность, цвета спектра, цвет и яркость фона.
5. «Остановить» завершает захват, отправляет нулевые уровни и возвращает подсветку к параметрам локального профиля. Перед запуском доступен прочитанный с клавиатуры профиль.

Аудио анализируется локально, не записывается в файл и не отправляется по сети. Микрофон и изображение экрана не захватываются. Используется приватный Core Audio process tap и временное приватное аудиоустройство, удаляемые при остановке. Переключение системного выхода перезапускает захват; сон Mac и отключение USB останавливают его. После сна или переподключения нажми «Запустить» снова. Цвета, фон, яркость и чувствительность восстанавливаются после перезапуска. Захват звука включается кнопкой «Запустить».

Передача идёт примерно 12 раз в секунду, без накопления устаревших кадров. Запись настроек и изображений временно приостанавливает музыкальные USB-команды. Обычные кнопки Play/Pause, Previous, Next и громкости используют отдельные HID-события. Реакция на Next/Previous зависит от активного проигрывателя и наличия очереди. Play/Pause и обе стрелки проверены пользователем в YouTube/Arc одновременно с визуализацией; стрелки работают в плейлисте. Для YouTube команда Next Track документирована как переход внутри плейлиста: [справка YouTube](https://support.google.com/youtube/answer/7631406?hl=ru). Приложение не подменяет эти команды браузерными сочетаниями клавиш.

Проверено на подключённой L99: приложение различает тишину и реальный тестовый звук, уровни передаются без ошибок; пользователь подтвердил: «все работает. и клавиши и волна». Другие аудиоустройства, защищённый контент и версии прошивок отдельно не проверялись. При отсутствии спектра проверь разрешение системного аудио в настройках конфиденциальности macOS.

```sh
bash scripts/build.sh
```

Скрипт запускает тесты Rust, собирает статическую библиотеку и нативное приложение. Сейчас целевая архитектура — `arm64`. Временные файлы находятся в `.build/`; другой путь можно задать переменной `L99_BUILD_ROOT`.

```sh
cargo test --manifest-path core/Cargo.toml
bash scripts/test_audio.sh
bash scripts/test_configuration.sh
cargo run --manifest-path core/Cargo.toml -- rgb-example
"./L99 for Mac.app/Contents/MacOS/L99forMac" --diagnose
"./L99 for Mac.app/Contents/MacOS/L99forMac" --metrics
"./L99 for Mac.app/Contents/MacOS/L99forMac" --read-config
```

Команды примеров, диагностики и `--metrics` ничего не отправляют в клавиатуру. `--read-config` посылает только команды чтения и выводит снимок конфигурации; команда сохранения во flash не используется. Вывод содержит пользовательские назначения и макросы и не предназначен для публичного репозитория. `--realtime-once` выполняет одну передачу текущего времени и показателей.
