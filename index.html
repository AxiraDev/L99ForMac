AULA L99 on Mac: common questions

Is this an AULA L99 driver for Mac?

It is an unofficial macOS configuration app using native USB interfaces. It does not run the Windows program or install a kernel extension.

Does it work over Bluetooth or 2.4 GHz?

Configuration currently requires wired USB. Firmware updates are not included.

Is L99 for Mac free?

Yes. It is free software under GNU GPLv3. Donations do not unlock any extra features.
