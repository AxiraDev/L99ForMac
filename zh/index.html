在 Mac 上使用 AULA L99：常见问题

这是 AULA L99 的 Mac 驱动吗？

这是使用 macOS 原生 USB 接口的非官方配置应用，不运行 Windows 程序，也不安装内核扩展。

支持蓝牙或 2.4 GHz 配置吗？

当前配置需要有线 USB。本版本不包含固件更新。

L99 for Mac 免费吗？

是的，应用采用 GNU GPLv3 自由软件许可证。捐赠不会解锁额外功能。
